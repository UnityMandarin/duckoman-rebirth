# World scenic variety V3

V3 addresses the request for scenery that moves with the journey and passes through many distinct places. The V2 single-field-per-chapter arrangement made long routes feel visually stationary. V3 uses 16 separate floorless scenic zones with full-cell connector art at boundaries and repeat joins. Gameplay geometry remains the authority: this change does not alter platforms, gaps, machine movement, enemies, bosses, camera setup, checkpoints, or saves. Furnace, Rescue, the Castle secret lair, and the Warden encounter retain their existing art/profile paths. The former opaque Regent arena overlay stays retired while its source art remains preserved.

The bounds come from the existing Castle route and chapter/room dimensions in `worldEnvironment.ts`, not newly introduced terrain. `scenicZones.ts` lists each corresponding image key. Each chapter's initial and terminal projected edges include 640px of coverage. A common vertical origin (`plan.top - 128`) preserves continuity across room height changes.

## Motion and joins

Each scenery tile is positioned at 0.8 times its authored world X and uses Phaser scroll factor (0.8, 1). A one-world-pixel camera move therefore advances the distant scenery by 0.8px horizontally, while vertical movement remains 1:1. Foreground structures stay at (1, 1). The world still uses the existing room-rooted structures and machine supports.

The connector PNGs are transparent atlases at the same native 1536×1024 size. Castle, Jail, and Crimson contain two equal 768px-wide cells; Outside contains three equal 512px-wide cells. The renderer registers each complete cell, preserving the artwork's natural transparent fringe, and aligns its measured opaque core center to the zone boundary or local repeat join. Native core widths are 48px for Castle/Jail/Outside and 32px for Crimson; the source atlas measurements and alpha bounds are documented in [WORLD_SCENIC_ART_V3.md](WORLD_SCENIC_ART_V3.md). Each zone gets a different connector variant where available. There is no crossfade or duplicate ghosted architecture.

Tile crops retain a stable global phase in full scenes and preview/practice windows. Full source images explicitly request Phaser's `__BASE` frame. Partial terminal frames use identifiers that include tile index and crop geometry, so a prior preview crop cannot leak into a later render. V3 art is loaded only for the matching Castle/Journey profile; Furnace, Rescue, and Castle secret profiles do not load these images.

## Assets, provenance, and budgets

All 20 V3 images (16 scenic plates and four connector atlases) were generated by the existing Luna Low image hand; code integration was also completed by Luna Low following the user's correction. Prompt provenance and source-image paths are recorded in [WORLD_SCENIC_ART_V3.md](WORLD_SCENIC_ART_V3.md). The selected atlases match their original image-generation outputs byte-for-byte; the earlier alpha-edited versions were replaced. All assets measure 1536×1024. PNG storage totals about 48.3 MiB across all chapters; per chapter it is 8.14 MiB Castle, 9.20 MiB Jail, 22.54 MiB Outside, and 8.41 MiB Crimson. Their conservative decoded RGBA budgets are 24 MiB for Castle/Jail/Crimson and 48 MiB for Outside, below the 60 MiB active-chapter cap. Original V2 and unrelated artwork remain preserved.

The active chapter's source-art budget is capped at 60 MiB. Outside has seven plates plus its connector atlas; the other chapters use three plates plus their atlas. Renderer image instances are static and bounded; no per-frame allocations, whole-chapter raster canvas, shader, lighting pass, or physics work is added. Structural kit images remain separate from the far-plane plates.

This was a targeted visual/runtime review, not a complete campaign playthrough or a hardware performance benchmark. User playtesting remains required.

Final regression after the correction: 65 test files / 453 tests pass, TypeScript and Vite production build pass, and `git diff --check` passes. The pre-existing large-bundle build warning remains. ### Release state

The subsequent Jail descent-camera experiment was rolled back in full after a gameplay regression report. Its per-frame `setDeadzone` call reset Phaser follow scroll. This release retains the established camera behavior and removes only the decorative dark pit-fill rectangles, preserving pit caps, spike art and death boundaries. The wider Jail camera experiment is not included.
